# Лабораторная работа №2. Работа с формами

## Задание

**Доработать форму обратной связи. Форма должна содержать следующие поля**:

- ФИО (текстовое) [x]
- Email (текстовое) [x]
- откуда узнали о нас (радио-кнопки) [x]
- тип обращения (жалоба/предложение, селектор) [x]
- текст сообщения (большое текстовое поле) [x]
- вложения (файл) [x]
- даю согласие на обработку персональных данных (чекбокс) [x]

**Вам нужно доработать оформление страницы, созданной на занятии, по вашему усмотрению, используя изученные CSS-свойства.**

**Сделать форму для аутентификации. Форма должна содержать следующие поля**: 

- логин (текстовое) [x]
- пароль (пароль) [x]
- "запомнить меня" (чекбокс) [x]

**Форма должна располагаться по центру страницы. Вокруг формы должно быть фоновое изображение, занимающее весь экран.**

[Пример формы обратной связи](http://edu.std-900.ist.mospolytech.ru/files/feedback.jpg)
